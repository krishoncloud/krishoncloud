### Research & Featured Work

**[Delta-V: Learned Physics Surrogate Platform](https://github.com/krishoncloud/delta-v)** · [Live demo](https://krishmalik-delta-v.hf.space/)

A modular platform for learning approximations of physical systems from simulation data, starting with three fluid-dynamics systems from Polymathic AI's *The Well*.

- Fourier Neural Operator surrogate models for turbulence, convection and shear flow.
- Next-state predictions, autoregressive rollouts, reference comparisons and explicit error reporting.
- A workflow for extending beyond fluids to additional physical-system domains.

`Scientific ML` `PyTorch` `FNO` `Surrogate Modeling`

**DepthViT: Channel-Asymmetric Vision Transformers** · *Google Summer of Code 2026, ML4Sci / CERN CMS*

Designed an architecture for particle-jet classification combining per-channel embeddings, channel-wise attention and Hierarchical Attention Pooling (HAP).

- Studied model scaling from **165K to 22M parameters** on HLS4ML jet data.
- Achieved **+1.69 percentage points Top-1 accuracy** over a matched-budget ViT-Tiny at 5.4M parameters, with fewer FLOPs.
- Trained and evaluated models on NERSC Perlmutter using multi-GPU workflows.

`Vision Transformers` `Attention` `HAP` `PyTorch Lightning` `HPC`

**[Symbolic Regression with Order-Invariant Embeddings](https://github.com/krishoncloud/SymbolicRegression-ML4sci-Krish-Malik)** · *Google Summer of Code 2025, ML4Sci / SYMBA*

Developed a sequence-to-sequence symbolic regression framework combining T-Net set embeddings and a transformer decoder for recovering symbolic expressions from numerical observations.

- Reported **92.8% exact recovery** and **99.6% token accuracy** in the final project results.
- Extended the work into a **first-author NeurIPS 2025 ML4PS workshop paper**, presented in San Diego.

`Symbolic Regression` `Transformers` `Representation Learning` `PyTorch`

**[Linear-Attention ViTs for CMS Mass Regression](https://github.com/krishoncloud/Linear-attention-ViTs---Krish-Malik)** · *GSoC 2026 preliminary task*

Built a linear-attention Vision Transformer with masked-autoencoder pretraining and joint classification/regression heads for detector images.

- **85.2% classification accuracy**, compared with **80.6%** for the from-scratch baseline.
- Joint invariant-mass regression with **R² = 0.6322**.

`Linear Attention` `MAE` `Particle Physics`
